# Integrity error/unable to verify app/unable to install/crashing
If you're using direct install Delta (THE DELTA FROM DELTA.BZ), delete it and reinstall. If it still says that, wait until the certificate for direct is updated or use the IPA method.

Integrity could not be verified error on ksign/esign :
If you're using Ksign/Esign to sign and install the Delta IPA, delete it and get another Ksign/Esign (i.e., try another enterprise certificate). Do that for every Ksign/Esign on https://khoindvn.io.vn until one says "untrusted developer" or all of them give an "integrity" error.

REMEMBER TO USE KHOINDVN ANTI-REVOKE DNS, AND DO NOT USE A VPN

If they all give an integrity error: # Channel Not Found

"Unable to verify app/An internet connection is required" - try to delete that Ksign/Esign and reinstall the SAME one. It might go away. If not, use another ksign/esign

"Delta/Ksign/Esign is no longer available" - your certificate expired. You need to get a new Ksign/Esign (delete your Delta and Ksign)

Crashing = your certificate is revoked. You need to get a new Ksign/Esign

Crashing = closing = kicking out
