# Unofficial iOS Direct Install
Unofficial iOS direct install is found at the following website: https://delta.bz

It is a signed Delta IPA made with a leaked enterprise certificate. The cert it uses is usually unrevoked and NOT on khoindvn.

⚠️ Contains more advertisements and takes longer to update. It's best to sign the official unsigned IPA.

Subscribe to skibidi tech's YouTube channel ( @skibiditech007 ) if you want to know when he updates direct install.

Since it is UNOFFICIAL, the Delta Team will NOT know when it will update when it is down or shows an integrity error.

# How to get it
1. Go to the website linked above (https://delta.bz).
2. Press "Direct Install" and press "Open" for the iTunes pop-up; you will then be prompted to install Delta — tap Install.
3. On your device, go to Settings → General → VPN And Device Management → Enterprise Apps → Trust.
4. Restart your phone if necessary, then enjoy Delta.

# How to update it
1. Delete the Delta app. Save your scripts first.
2. Reinstall it.
