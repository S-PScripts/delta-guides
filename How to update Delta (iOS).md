# How to update Delta (iOS)
When Delta updates, you can't just click Upgrade; you need to do this:
1. Delete your Delta app. Save your scripts if needed before doing this: https://discord.com/channels/1279547031945220147/1517265356765532281
2. Go to https://deltaexploits.dev or https://deltaexploits.gg and download the latest IPA # Channel Not Found.
(You can also use direct install if it's not down)
3. If you're using IPA, import, sign, and install it in your signer app (KSign, ESign, Feather, SideStore). Or sideload (sideloadly, iloader, impactor)
4. Add your scripts back if needed, then you are done!

If you complain to us about Direct being down, genuinely shut up. It's unofficial. Skibidi tech makes it, so bother his ass, not us. https://m.youtube.com/@skibiditech007/videos

If you're using the latest IPA but you're getting an upgrade error, delete the delta app then sign and install again

If it still says to upgrade, wait for an announcement from the developers saying that delta ios has updated. then try again
