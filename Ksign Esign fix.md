# When will KSign/ESign be fixed?
When you say "KSign is down", no, it's not. Still works for some people.

If a ksign/esign does not work for you due to an integrity error, it will NEVER work (unless you are lucky with a factory reset).

We did not create Esign/Ksign.

New Ksigns/Esigns come out when new enterprise certificates are leaked (which are used to sign the Ksign/Esign IPA).

Leaking is unpredictable. There is no schedule.
