# Ready / signing stuck fix
To fix this issue, follow the steps:
1. At the bottom bar of Ksign, tap "Settings".
2. Press "Update SSL certificates" and try signing and installing again. If that doesn't work, go back to Settings.
3. Press Installation (also called Server and SSL).
4. Change semi-local to fully local (if it's already on fully local, change it to semi-local)
5. Press Suspend.
6. Try to sign and install again.

If that doesn't work, change it back to how it was before. Switch it back and forth a few times.

Still not working? Delete and reinstall the Ksign.

If it continues to fail, get another Ksign or try Esign instead.

Don't already have Delta installed.
