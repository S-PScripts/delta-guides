# Whitelist error / Constant kicking fix
If you join a Roblox game only to get kicked with this message, this is unrelated to Delta's keysystem; it is being caused by a script (if you know what script it is, tell me. I've seen this error quite a few times).

If you don't know what script is causing it, do the following:
1. Find the Delta folder.
To do this on Android: install ZArchiver from the Play Store, then go to the path: storage/emulated/0
To do this on iOS: open the Files app, find "On my iPhone/iPad"
2. Delete the Autoexecute folder (if you know what script is causing it, delete that script only)

Yeah, that's all.
