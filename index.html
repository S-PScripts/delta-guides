Platform Support

Android
Working (arm64 only)
There are no plans as to when arm32 will be re-added, if ever.
iOS
Working (IPA only, not direct!)
Direct is unofficial.
Windows
Unsupported (as a native client)
You need to use an emulator.
macOS
Unsupported (as a native client)
For Intel chips your only choice is to use another executor, such as Prism. You can use an emulator if you have a Silicon (M-Series) chip.
Linux
Unsupported (as a native client)
Except ChromeOS. Use dev mode on ChromeOS or Linux developer environment + ADB.
For Linux you can use Waydroid libhoudini.
