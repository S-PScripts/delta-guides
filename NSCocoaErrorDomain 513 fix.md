# NSCocoaErrorDomain 513 fix
1. Go to Files.
2. Find the Delta IPA you just downloaded.
3. Rename it to add .zip to the end (NAME.ipa.zip).
4. Tap the zip file to make a Payload folder.
5. Hold this payload folder and compress it to make a zip (payload.zip).
6. Rename this zip file to replace .zip with .ipa (payload.ipa).
7. Import it, and it'll work.
