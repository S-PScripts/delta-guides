# Is your script not working? Do this!
1. Execute the script.
2. open /console. If you decided not to verify your age, execute infinite yield and type in console in its command bar.
3. Scroll to the bottom and look for errors in the console (if any).
4. Try executing the script again with a VPN on.
5. If it's supposed to be a universal script, try another game.
6. Create a support forum and do the following.

A- send the script(s) that isn't/aren't working.
B- send the game(s) you tried it in.
C- include the platform (ios/android).
D- If it doesn't crash, include screenshots of the errors you got from executing the script, if any.
E- If you crash upon executing it, send the crash logs.
F- Did it work in the previous version?

Usually, your script just SUCKS, and it's not Delta being bad. Also, make sure you're using the latest version of Delta and from the original website (deltaexploits.dev/.gg). If you are not sure, delete Delta and reinstall, then repeat the steps above
