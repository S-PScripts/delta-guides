# Delta Android Installation
1. Delete Roblox.
2. Go to https://deltaexploits.gg or https://deltaexploits.dev
3. Press Download to obtain the APK.
4. Go to the Downloads section of your browser and tap the APK.
5. Install "Roblox"; this is actually Delta.
6. Open Roblox and enable file permissions (used to save settings for both Delta itself and scripts + auto-execute).

- If neither website is loading, then use a VPN like Cloudflare WARP or Proton VPN
- Android VNG / iOS VNG is not supported due to lack of demand
- If it gets stuck downloading at 100%, use FireFox (install from Play Store)
- Delta is not on arm32 anymore.
